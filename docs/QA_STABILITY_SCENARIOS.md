# 안정성 시나리오 매트릭스

2026-07-27 교차 분석에서 수정한 안정성 결함 3건은 정적 검증(컴파일·게이트·
사보타주 테스트)까지만 증명됐고, **크래시/프리즈 부재는 실게임에서만 확인
가능합니다.** 일반 전투 한 판으로는 아래 조건이 만들어지지 않으므로, 각
시나리오의 조건을 의도적으로 구성해야 합니다.

공통 준비:

- `debugVerboseLogging=true`, `debugHudNotifications=true`
- **함정 어픽스 준비(수십 초)**: 디버그 토글이 켜져 있으면 Prisma 패널 고급 탭에
  "선택 베이스에 함정 어픽스" 버튼이 보인다. 룬워드 탭에서 무기를 베이스로 선택한 뒤
  버튼을 누를 때마다 함정 어픽스(곰덫→룬→역병→타르→흡수→혼돈)가 하나씩 부여된다.
  무기 2자루에 2~3종씩 채우면 시나리오 전제가 완성된다. "스타트 재련 오브 +3"도
  디버그 세션에서는 소지 여부와 무관하게 반복 지급된다.
- 시나리오 시작 전 수동 저장(실패 시 재현용)
- 크래시 발생 시: `CalamityAffixes.log` 마지막 50줄과 크래시 로거 산출물(설치돼
  있다면)을 함께 보관
- 대상 소환이 필요하면 콘솔 `help "<이름>" 4`로 BaseID를 찾아
  `player.placeatme <BaseID> <수>`를 사용

판정 기준(모든 시나리오 공통): CTD·프리즈 없음, 로그에 `[error]
CalamityAffixes:` 없음, 시나리오 종료 후 proc·함정이 계속 정상 작동(발동 영구
멈춤 회귀 감시).

---

## S1. 함정 셀 detach (v1.7.3 P0-2 수정 검증)

**수정 내용:** 함정이 소속 셀 포인터를 TTL 동안 들고 있다가 셀 언로드 후 해제된
메모리를 참조하던 CTD.

**왜 일반 전투로 부족한가:** 함정 TTL이 남은 채로 셀이 언로드되는 상황 자체가
드뭅니다. 언로드를 의도적으로 만들어야 합니다.

| 단계 | 절차 |
|---|---|
| 1 | 함정 어픽스 장착, 전투로 함정 3개 이상 설치(마커 확인) |
| 2 | 함정 TTL이 남은 상태에서 **즉시 셀 이탈**: 실내면 문으로 나가고, 실외면 빠른 이동 |
| 3 | 언로드 상태에서 TTL이 만료되도록 60초 이상 대기(콘솔 대기 아님, 실시간) |
| 4 | 원래 셀로 복귀, 함정 위치 확인 |
| 5 | 조합 반복: 실내→실외, 실외→실내, 빠른 이동, `coc` 이동 각 1회 이상 |

**추가 확인:** 복귀 후 잔류 마커/이펙트가 없어야 하고, 새 함정 설치가 정상
작동해야 합니다.

## S2. 트리거 인덱스 스냅샷 (v1.7.3 P1-1 수정 검증)

**수정 내용:** 발동 목록 순회 중 발동 효과가 엔진에 재진입하고 장착 이벤트가
같은 목록을 재구축하면 순회 중 메모리가 무효화되던 CTD(실체는 use-after-free).
순회 시작 시점의 사본을 사용하도록 수정.

**왜 일반 전투로 부족한가:** "발동 처리 도중 장착 재구축"이라는 타이밍 충돌을
자연 플레이에서 반복적으로 만들기 어렵습니다.

| 단계 | 절차 |
|---|---|
| 1 | 발동형 어픽스 4개 이상(히트 트리거 위주) + 피격 트리거 1개 이상 장착 |
| 2 | 다수 적(5+)과 교전하며 proc이 연속 발동하는 상태 유지 |
| 3 | 전투 중 **핫키로 무기/방패 스왑을 연타** — 스왑마다 장착 재구축 발생 |
| 4 | proc HUD 알림이 뜨는 순간에 맞춰 스왑하는 시도를 5분간 반복 |
| 5 | 즐겨찾기 메뉴를 열고 장비 교체 → 즉시 닫고 공격을 반복 |

**추가 확인:** 세션 후에도 proc이 계속 발동해야 합니다(멈추면 가드 카운터 회귀
의심). 로그의 `RebuildActiveCounts` 라인 수가 스왑 횟수와 일관돼야 합니다.

## S3. 함정 틱 다중 상태 전이 (v1.7.3 P1-2 수정 검증)

**수정 내용:** 함정 틱의 주변 액터 스캔을 틱당 1회로 통합. 다수 함정이 같은
틱에 발동·제거·만료되는 경로가 핵심 위험.

**왜 일반 전투로 부족한가:** 함정 여러 개가 같은 틱에 상태를 바꾸는 상황은
함정을 몰아서 설치하고 적 무리를 한꺼번에 유인해야 나옵니다.

| 단계 | 절차 |
|---|---|
| 1 | 함정 어픽스 2~3종 동시 장착 |
| 2 | 좁은 공간에 함정 6개 이상을 몰아서 설치 |
| 3 | `player.placeatme`로 적 8마리 이상 소환해 함정 지대로 유인 — 동시 다중 발동 유도 |
| 4 | 이어서 함정을 다시 몰아 설치한 뒤 발동시키지 않고 방치 — TTL 동시 만료 유도 |
| 5 | 고액터 환경(도시 장터 등)에서 2~4를 1회 반복 |

**추가 확인:** 앞 함정이 처치한 대상이 뒤 함정에서 제외되는 기존 동작이
유지되는지(중복 발동 로그 없음), 프레임 히치가 체감 수준인지 기록합니다.
