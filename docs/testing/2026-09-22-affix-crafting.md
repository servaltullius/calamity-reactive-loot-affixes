# 확인·선택 재련·정제 테스트 빌드

정식 1.7.5를 기반으로 한 미출시 변경. 코드/호스트 테스트와 게임 검증을 구분한다.

## 확정한 규칙

- 확인 스크롤 1개: 일반 어픽스가 없는 장비에 접두 1 + 접미 0~2를 부여한다. 개수 확률은 60%/30%/10%다. 기존 룬워드만 있는 장비에도 사용할 수 있다.
- 재련 오브 2개: 선택한 일반 어픽스 하나를 같은 종류(접두/접미)의 다른 어픽스로 교체한다. 다른 어픽스, 해당 성장 상태, 슬롯 수, 룬워드는 유지한다. 같은 접미 계열 중복을 금지한다. 횟수 제한은 없다.
- 슬롯 확장: 1→2는 재련 오브 2개, 2→3은 4개. 기존 어픽스 및 룬워드 상태 유지.
- 정제 오브 1개(test2부터): 슬롯 수를 유지한 채 일반 어픽스 전부를 한 번에 다시 굴린다(접두 1 + 서로 다른 계열 접미). 기존 일반 어픽스의 성장 상태는 초기화하고, 같은 어픽스가 다시 나와도 새로 시작한다. 결과가 이전과 완전히 같으면 재료를 쓰지 않고 실패한다. 룬워드 및 룬워드 진행/성장 상태는 보존한다. 패널에서 6초 내 두 번째 클릭으로 확인한다.
- 구버전 구성(알 수 없는·슬롯 없는 어픽스, 중복 접미 계열, 접두/접미 배치 오류)은 확인·선택 재련·확장이 거부되고, 정제만 허용해 정상 구성으로 다시 굴린다. 룬워드 상태 충돌은 정제로도 고치지 않는다(디버그 초기화 대상).
- 새 재화 드랍: 기존 적격 적대 시체 조건 및 중복 처리 장부를 공유한다. 확인 20%, 정제 2%(MCM에서 조정, `user_settings.json`에 저장)에 시체 배율을 적용해 각각 독립 판정한다. 보스 확정/천장은 새 재화에 적용하지 않는다. 기존 룬·재련 보상은 유지한다.
- 무료 전체 상태 초기화는 디버그 도구로만 사용한다. 일반 플레이의 전체 리롤과 구버전 구성 복구는 정제를 이용한다.
- 게임 인벤토리의 확인 스크롤은 제작 재료(MISC)이며, 마법처럼 장착하는 스크롤이 아니다. Prisma 패널에서 사용한다.
- 새 ESP FormID: 확인 스크롤 0xB0F, 정제 오브 0xB10. 기존 레코드 번호를 이동하지 않는다.

## 인게임 확인 필요

기존 프로필/세이브를 보존한 별도 테스트 환경에서 전체 ZIP을 사용한다. DLL 단독 교체로는 새 재화가 추가되지 않는다.

1. 기존 1/2/3어픽스 및 룬워드 장비가 그대로 보이는지 확인한다.
2. 일반 어픽스가 없는 장비를 확인하고 재료 1개만 감소하는지, 다시 확인은 차단되는지 확인한다.
3. 각 슬롯을 선택 재련하고 나머지 어픽스와 성장 상태, 룬워드가 유지되는지 확인한다.
4. 재료 부족 상태와 버튼 연속 클릭에서 추가 차감/변경이 없는지 확인한다.
5. 1/2/3어픽스 장비에서 정제를 두 번 눌러 슬롯 수는 그대로이고 일반 어픽스만 바뀌는지, 룬워드와 그 성장 상태는 유지되는지 확인한다. 특히 **3어픽스(접두 1 + 접미 2) 장비의 선택 재련과 정제**가 동작하는지 확인한다(test1 결함).
6. 정제 확인 대기 중 다른 장비를 고르면 그 장비에는 다시 확인을 요구하는지 확인한다.
7. 저장·로드, 장비 탈착, 보관·회수 후 결과가 유지되는지 확인한다.
8. 적대 적 시체에서 새 재화가 보이고, 같은 시체 재접근/중복 사망 이벤트로 재생성되지 않는지 확인한다.
9. 무기를 뽑은 상태의 패널 열기·닫기와 자동 소환수 아군 피해 보호도 회귀 확인한다.

빠른 수동 테스트는 MCM 디버그 알림을 켠 뒤 고급 탭 디버그의 **스타터 제작 재료**(재련 오브 3, 확인 스크롤 3, 정제 오브 1)를 쓰거나, 콘솔의 `help "Scroll of Identification" 4`와 `help "Scouring Orb" 4`로 현재 로드 순서의 FormID를 찾고, `player.additem <표시된 FormID> 10`으로 재료를 마련할 수 있다.
