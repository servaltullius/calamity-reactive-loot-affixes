- 올릴 파일: `G:\TAKEALOOK\downloads\CalamityAffixes_MO2_v2.2.2_2026-09-28.zip`(GitHub v2.2.2 릴리스 자산. rc는 넥서스에 올리지 않는다. SHA256은 같은 릴리스의 `.sha256`)
- 이미지·GIF: `G:\TAKEALOOK\downloads\Calamity-2.2.2-nexus-media\`(GIF·단축키 안내·인게임 사진), `G:\TAKEALOOK\downloads\Calamity-2.2.0-nexus-images\`(2.2.0 규칙으로 다시 만든 대표 이미지·패널 캡처)
- 세부 규칙 참고 문서: `docs/NEXUS_DESCRIPTION.md`, 영문 효과 목록: `docs/EFFECTS_EN.md`

## 2.2.2 업데이트 때 할 일

페이지는 2.1.3으로 열려 있다. 2.1.4는 rc만 나오고 정식은 건너뛰었다. 2.2.1·2.2.2는 룬워드 이름 표시만 고친 패치라서, 2.2.0 이후 버전을 이미 올렸다면 1~3만 하면 된다. 2.2.0을 아직 안 올렸다면 전부 한다.

1. **Files:** 2.2.2 ZIP을 Main Files로 올리고(2절), 이전 파일은 Old files로 옮긴다.
2. **General:** 버전을 `2.2.2`로 바꾼다.
3. **Changelogs:** 3절 맨 위의 2.2.2 항목을 추가한다. 넥서스에 아직 없는 2.2.1·2.2.0 항목도 함께 넣는다.
4. **이미지:** 넥서스 이미지 갤러리의 2.0 대표 이미지와 패널 캡처 01~04를 지우고 `Calamity-2.2.0-nexus-images\`의 새 파일로 바꾼다(4절 표). 새 대표 이미지를 페이지 대표(Primary)로 지정한다. 옛 대표 이미지에는 "6회 제한"이 없고 정제 드랍률이 2%로 적혀 있다. 단축키 안내와 인게임 사진 11·12도 `Calamity-2.2.2-nexus-media\`의 새 파일로 바꾼다. 설명문(5절)은 가벼운 GIF의 imgur 주소로 채워 두었으므로 그대로 붙여 넣으면 된다.
5. **설명문:** 5절의 두 블록(영어·한국어)을 다시 붙여 넣는다. 제작 규칙(선택 재련 장비당 6회, 정제가 리셋, 교환 10:1)과 정제 오브 드랍률(4%), 한국어 메뉴 이름("칼라미티 패널 토글")이 바뀌었다.
6. **고정 댓글:** 6절처럼 한국어 줄의 메뉴 이름을 "칼라미티 패널 토글"로 고친다.
7. **아카라이브:** 새 글을 올릴 거라면 [아카라이브 소개글](2026-09-28-arcalive-post-v2.2.2.md)을 쓴다.

## 1. 기본 정보

- **이름:** `Calamity 2 - Reactive Loot and Affixes (Diablo2 PoE)` (옛 제목의 검색어를 유지하면서 구분된다)
- **버전:** `2.2.2`
- **분류(권장):** Gameplay (대안: Combat)
- **요구 모드(Requirements 탭):**
  - SKSE64 (넥서스 외부): https://skse.silverlock.org/
  - Address Library for SKSE Plugins: https://www.nexusmods.com/skyrimspecialedition/mods/32444
  - Prisma UI: https://www.nexusmods.com/skyrimspecialedition/mods/148718
- **권장 모드(설명문에 적혀 있음, 요구 모드로는 넣지 않음):** SkyUI(12604)·MCM Helper(53000) — 설정과 패널 키 변경에 필요, KID(55728)
- **짧은 소개(Brief overview):**

```text
Diablo 2 / PoE-style affixes and 94 runewords for your own Skyrim gear, via SKSE. Identify with a scroll, refine one chosen affix with Reforge Orbs, or reroll them all with a rare Scouring Orb. Materials drop only from enemies you kill. Open the panel with F11.
```

### 권한 (Permissions 단계)

- **Third-party content:** "예"(다른 사람 콘텐츠를 허락·오픈 라이선스로 사용). ZIP의 파일은 모두 직접 만든 것이지만 DLL에 오픈소스 코드(CommonLibSSE-NG, spdlog, fmt, nlohmann/json, rapidcsv, Xbyak)가 들어간다. 라이선스 고지는 ZIP의 `Docs/THIRD_PARTY_NOTICES.txt`에 있다.

## 3. 변경 이력 (Changelogs 탭)

첫 업로드(2.1.3) 때 2.0.0~2.1.3을 한꺼번에 넣었다. 이후에는 새 항목만 맨 위에 추가한다.

```text
2.2.2
- The runeword name after a finished base's name follows your UI language too ("[Runeword: Chaos]" in English mode, "[룬워드: 카오스]" in Korean mode), and three more HUD messages use the English name.
- 룬워드를 완성한 장비 이름 뒤의 룬워드 이름도 UI 언어를 따릅니다. HUD 알림 세 개도 영어 이름으로 맞췄습니다.

2.2.1
- Runeword names in the panel now follow your UI language. English mode showed the Korean names (for example 스피릿 instead of Spirit) in the recipe list, the selected recipe, and the status line. Recipe search finds either name in any mode.
- Runeword HUD messages ("Runeword Recipe:", "Runeword Complete:") now use the English name, which the default HUD font can always show.
- 패널의 룬워드 이름이 UI 언어를 따릅니다. 영어 모드에서도 레시피 목록·선택한 레시피·상태 줄에 한국어 이름이 나오던 문제를 고쳤습니다. 레시피 검색은 모드와 관계없이 두 이름 모두로 찾습니다.
- 룬워드 HUD 알림("Runeword Recipe:", "Runeword Complete:")은 영어 문장이므로 영어 이름을 씁니다.

2.2.0
- Selected reforge is now limited to 6 per item. When they run out, a Scouring Orb rerolls every affix and gives the 6 back. Slot expansion does not count. The panel shows how many are left (for example 4/6).
- Scouring Orbs drop more often (2% -> 4% by default), and 10 Identify Scrolls now trade for one (was 15).
- The Korean UI now spells the mod 칼라미티.
- Existing saves work. Each item's reforge count is saved with your game; existing items start at 0.
- 선택 재련이 장비마다 6회로 바뀌었습니다. 다 쓰면 정제 오브로 전부 다시 굴리면서 6회를 되돌려 받습니다. 슬롯 확장은 횟수에 들어가지 않고, 패널에 남은 횟수(예: 4/6)가 나옵니다.
- 정제 오브 기본 드랍률 2% -> 4%, 확인 스크롤 교환 15개 -> 10개로 조정했습니다.
- 한국어 UI의 모드 이름을 "칼라미티"로 통일했습니다.
- 기존 세이브를 그대로 쓸 수 있습니다. 장비별 재련 횟수는 세이브에 저장되며 기존 장비는 0회부터 시작합니다.

2.1.3
- The download now includes license notices for the open-source libraries built into the DLL (Docs/THIRD_PARTY_NOTICES.txt). Nothing in the game changes.
- DLL에 들어가는 오픈소스 라이브러리의 라이선스 고지(Docs/THIRD_PARTY_NOTICES.txt)를 포함했습니다. 게임 내용은 바뀌지 않습니다.

2.1.2
- Every runeword now shows one full name in tooltips, the panel, and active effects. Seven names had lost all but their first word ("Runeword Holy" is now "Runeword Holy Thunder"), Korean tooltips now use the panel list's names, and effect names spell out CTA, CoH, HOTO, and BotD.
- 룬워드 이름을 툴팁·패널·마법 효과 창에서 하나로 통일했습니다(잘린 이름 7개, 목록과 다르던 한국어 이름 37개, 효과 이름 줄임말).

2.1.1
- The Selected Base Affixes box no longer hides the other affixes behind a long first one.
- 선택 베이스 어픽스 상자에서 첫 어픽스가 길면 나머지가 가려지던 문제를 고쳤습니다.

2.1.0
- Trade spare Identify Scrolls one way: 3 for a Reforge Orb, 15 for a Scouring Orb.
- 남는 확인 스크롤을 재련 오브(3개)나 정제 오브(15개)로 바꿀 수 있습니다(한 방향).

2.0.1
- Crafting dashboard counts line up, and rune grid labels are no longer cut off.
- 제작 재료 대시보드 정렬과 룬 그리드 칸 문구 잘림을 고쳤습니다.

2.0.0
- Crafting reworked: Identify Scroll (1-3 affixes), Reforge (one chosen affix, 2 Reforge Orbs), Scouring Orb (reroll every affix, keep the slots).
- New currencies drop from hostile corpses: Identify Scroll 20%, Scouring Orb 2% (adjustable in MCM).
- Crafting dashboard in the panel, and panel layout fixes at wide and small sizes.
- Everything since the old page's 1.2.21: corpse-only currency drops, slot expansion, trap markers, summon friendly-fire protection, combat freeze fixes, and more (full list on GitHub).
- 제작을 확인 스크롤(1~3개 부여) · 선택 재련(어픽스 하나 교체) · 정제 오브(전체 리롤)로 개편했습니다.
- 새 재화 2종이 적 시체에서 나옵니다(확인 20%, 정제 2%, MCM에서 조정).
- 제작 재료 대시보드와 넓은·작은 패널의 표시 잘림 수정, 구 페이지 1.2.21 이후 반년 치 개선(GitHub CHANGELOG)이 들어 있습니다.
```

## 6. 고정 댓글 (Sticky)

사람들이 가장 많이 헷갈리는 **패널 단축키** 안내다. 페이지를 연 직후 올리고 고정한다.

```bbcode
[b]Can't open the panel? / 패널이 안 열리나요?[/b]
[list]
[*]Default key is [b]F11[/b]. Change it: ESC > System > Mod Configuration > Calamity Affixes > Hotkey & Debug > Toggle Calamity Panel. It works once you close the menu (needs SkyUI + MCM Helper).
[*]The current key is shown at the bottom of the Calamity item tooltip. Gamepad buttons can't open it.
[*]Still nothing: MCM > Prisma UI > Toggle Panel (Button), then Check Prisma UI Status. Prisma UI is required.
[/list]
[list]
[*]기본 키는 [b]F11[/b]입니다. 변경: ESC > 시스템 > 모드 설정 > Calamity Affixes > 단축키·디버그 > 칼라미티 패널 토글. 메뉴를 닫으면 적용됩니다(SkyUI + MCM Helper 필요).
[*]Calamity 아이템 툴팁 아래에 현재 키가 표시됩니다. 게임패드 버튼으로는 열 수 없습니다.
[*]그래도 안 되면 MCM > 프리즈마 UI > 패널 토글(버튼), 이어서 Prisma UI 상태 확인. Prisma UI는 필수입니다.
[/list]
```

댓글에 답할 때 참고할 단축키 사실관계(코드 기준):

- 기본 키는 `F11`이다. MCM에 키를 지정하지 않았으면 이 키로 열린다.
- 월드와 인벤토리 어디서든 열린다. 메인 메뉴·로딩 화면·캐릭터 생성 중에는 열리지 않는다.
- 게임패드 버튼으로는 열 수 없다. 키보드 키를 써야 한다.
- MCM `Calamity Affixes › Hotkey & Debug › Toggle Calamity Panel`에서 바꾼다. MCM(저널 메뉴)을 닫는 순간 새 키가 적용된다.
- 키를 바꾸려면 SkyUI와 MCM Helper가 필요하다. 둘이 없으면 F11로 열린다.
- Calamity 아이템 툴팁 아래에 현재 키가 `Open/Close Panel: <키>`(한국어 UI는 `패널 열기/닫기: <키>`)로 표시된다.
- 단축키가 먹지 않으면 MCM `Prisma UI › Toggle Panel (Button)`으로 바로 열 수 있고, 같은 페이지의 `Check Prisma UI Status`로 Prisma UI 상태를 확인한다.
