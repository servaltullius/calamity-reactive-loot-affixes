# Calamity - Reactive Loot & Affixes v1.7.5

v1.7.5 정식 릴리스입니다. RC6의 전투 프리징 수정·일반 공격 발동·중복 옵션 강화에 **Calamity 자동 소환수의 아군 피해 보호**를 추가했습니다.

## 자동 소환수 보호

- Calamity 장비 효과로 자동 소환된 패밀리어·정령이 플레이어와 아군의 공격으로 피해를 받거나 적대화하는 문제를 보완했습니다.
- 정확히 식별한 Calamity 소환 개체에 아군 피격 무시를 적용하고, 중첩 피해 및 유해 마법·무기 인챈트를 차단합니다. 소환수의 비적대 대상 공격·폭발 보호도 유지합니다.
- 적이 소환수에게 주는 피해, 치유 효과, 일반 수동 소환수의 기존 규칙은 유지하도록 구성했습니다.
- 소환 개체의 보호 정보를 별도 코세이브 레코드에 저장하고 로드 후 복원합니다.
- 소환수 보호 테스트 중 발생한 시작 CTD는 함수 테이블 선택 오류로 확인해 수정했습니다. 같은 잘못된 테이블 선택은 이제 컴파일 단계에서 거부됩니다.

## 전투·장비 성장

- 전투 중 Calamity 상태 락과 Skyrim 마법효과 이벤트 락이 서로를 기다리는 교착 경로를 수정했습니다.
- 곰 덫은 일반 무기 적중에서 기본 40%, 치명 시전 7종은 일반 근접 적중에서 주문에 따라 35% 또는 45%로 발동합니다. 치명타·강공격에는 평타 확률을 중복 판정하지 않으며 기존 ICD를 공유합니다.
- 서로 다른 장비에 붙은 동일 표준 발동 어픽스는 최대 3개까지 확률을 점감 합성합니다. 단계형 접미는 장착 티어를 합산해 최대 T3까지 강화됩니다.
- 근접 치명타·강공격은 서로 다른 치명 시전 주문을 최대 2개까지 발동합니다. 일반 근접 공격과 활·석궁은 최대 1개를 유지합니다.
- 일반 어픽스 슬롯을 `1 → 2 → 3`으로 확장하고, 적격 드래곤 처치 시 시체에서 룬 조각 1개와 재련 오브 1개를 확정 획득할 수 있습니다.
- 바닐라 모델을 사용하는 함정 표시, 곰덫 열림·발동·재장전 애니메이션, 어픽스 중심 Prisma 패널도 포함합니다.

## 확인한 범위

- 2026-09-22 사용자가 최종 소환수 보호 수정본을 테스트하고 “보호 잘 되는것같아”라고 확인했습니다. 앞서 보고된 시작 CTD를 수정한 빌드의 결과입니다.
- 이전 전투 프리징 수정과 슬롯 성장·드래곤 보상도 사용자 인게임 확인을 받았습니다.
- DLL 빌드, Python 187개·생성기 166개 테스트, SKSE/호스트 검사, 소환수 보호·저장 레코드·중첩 피해 회귀 검사와 배포 패키지 검증을 수행했습니다.
- 모든 소환 종류·적 공격·저장/로드·다른 모드 조합을 각각 인게임 검증했다는 뜻은 아닙니다. 보호 등록과 차단 여부는 `CalamityAffixes.log`에 기록됩니다.

## 설치와 업데이트

1. 게임을 종료하고 설정과 세이브를 보관합니다.
2. **`CalamityAffixes_MO2_v1.7.5_2026-09-22.zip`**을 MO2에서 기존 Calamity 모드에 **Replace**로 설치합니다.
3. `CalamityAffixes RC6 SummonFix1/2 - DLL Test` 같은 임시 DLL 모드는 비활성화합니다. 정식 DLL보다 우선 적용되지 않게 해 주세요.
4. 이전 버전에서 이미 소환된 개체는 사라진 뒤 새로 소환합니다. 예전 세이브에는 해당 개체의 보호 식별 기록이 없을 수 있습니다. 새 게임은 요구하지 않습니다.
5. SKSE로 실행합니다.

무기를 든 상태에서 패널을 열 때 멈추거나 닫은 뒤 조작이 풀리지 않던 문제는 별도 Prisma UI 1.5.1 환경에서 해결을 확인했습니다. Prisma UI는 이 ZIP에 포함되지 않습니다.

공개 자산은 **MO2 ZIP, ZIP SHA256, DLL, ESP** 네 개입니다. 일반 설치에는 전체 ZIP을 사용하세요. 일치하는 PDB는 GitHub Actions의 별도 심볼 산출물로 보존합니다.
