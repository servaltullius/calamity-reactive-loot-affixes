# Calamity - Reactive Loot & Affixes v2.2.2

v2.2.2는 **2.2.1의 룬워드 이름 수정에서 빠진 곳**을 마저 고친 릴리스입니다. 게임 동작, ESP, 코세이브, 게임 데이터는 2.2.1과 같습니다.

## 고친 점

- **베이스 이름 뒤의 룬워드 이름이 UI 언어를 따릅니다.** 룬워드를 완성한 장비는 이름 뒤에 룬워드 이름이 붙는데, 여기에는 영어 모드에서도 한국어 이름이 나왔습니다. 베이스 목록, 작업 베이스, 선택 아이템 이름에 모두 적용되고, 게임 중 언어를 바꾸면 바로 따라 바뀝니다.

  | UI 언어 | 표시 |
  | --- | --- |
  | 영어 | `렘넌트 장갑*** [Runeword: Chaos]` |
  | 한국어 | `렘넌트 장갑*** [룬워드: 카오스]` |
  | 이중 언어 | `렘넌트 장갑*** [Runeword: Chaos / 카오스]` |

  장비 이름 자체(예: 렘넌트 장갑)는 게임 데이터에서 오므로 게임 언어를 따릅니다.

- **HUD 알림 세 개도 영어 이름을 씁니다.** 2.2.1은 이름을 쓰는 곳마다 따로 고치다가 세 곳을 놓쳤습니다.
  - 베이스를 고를 때의 "Runeword Base: … | 이름"
  - Check Status 버튼의 "Runeword Status:"
  - 변환이 막혔을 때의 실패 알림

  이제 HUD 문장은 모두 한 함수로 영어 이름을 가져오고, 한국어 이름을 직접 읽는 코드가 새로 생기면 테스트가 실패합니다.

## 호환성

- 기존 세이브를 그대로 쓸 수 있습니다. 코세이브 형식은 2.2.0과 같습니다.
- DLL과 패널은 같은 ZIP으로 함께 설치하세요. 새 패널은 이전 DLL과 함께 쓰면 예전처럼 한국어 이름을 보여 줍니다.

## 확인한 범위

- 실제 패널을 헤드리스 브라우저로 띄워 영어·한국어·이중 언어 모드에서 베이스 목록, 작업 베이스, 선택 아이템 이름을 확인했습니다. 게임 중 언어를 바꾼 경우도 확인했습니다. 2.2.1의 레시피 이름 표시와 검색도 다시 확인했습니다.
- 패널 동작 테스트와 SKSE 정책 검사를 추가했습니다. HUD 문장이나 패널 문구에 한국어 이름이 다시 들어가면 실패하는 소스 검사도 추가했습니다. 이 검사는 수정을 빼면 실패하는 것을 확인했습니다. Python·생성기·SKSE 검사와 배포 패키지 검증을 통과했습니다.

## 설치와 업데이트

1. **`CalamityAffixes_MO2_v2.2.2_2026-09-28.zip`** 전체를 설치합니다. DLL과 패널이 함께 바뀌었으므로 MO2에서 기존 Calamity 모드를 **Replace**하세요.
2. 새 게임은 필요하지 않습니다.

Prisma UI는 이 ZIP에 포함되지 않습니다. 공개 자산은 **MO2 ZIP, ZIP SHA256, DLL, ESP** 네 개입니다.
