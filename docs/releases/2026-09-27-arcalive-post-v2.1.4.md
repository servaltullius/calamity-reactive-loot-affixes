■ 어떤 모드인가요

- 아이템에 어픽스가 저절로 붙지 않아요. 착용한 장비를 골라서, 처치한 적의 시체에서만 나오는 재화로 직접 키웁니다.
- 접두 73개, 접미 66개, 룬 33종으로 만드는 룬워드 94개
- 적중·피격·처치·저체력 때 주문, 함정, 원소 전환, 소환, 시체 폭발 같은 효과가 발동해요.
- 장비마다 룬워드 1개 + 일반 어픽스 최대 3개(접두 1 + 접미 2)
- 툴팁에서 어픽스를, 패널에서 전체 빌드를 확인할 수 있어요. 한국어·영어 UI를 지원합니다.

【이미지: 10-ingame-combat.jpg】


■ 먼저 읽어 주세요: 패널 여는 법

제작은 전부 "칼라미티 패널"에서 해요. 이걸 못 찾으셔서 헤매는 분이 많았습니다.

- 기본 키는 F11이에요. 월드·인벤토리 어디서든 열리고, 다시 누르거나 ESC·닫기 버튼으로 닫습니다.
- 키 바꾸기: ESC > 시스템 > 모드 설정 > Calamity Affixes > 단축키·디버그 > 칼라미티 패널 토글 에서 새 키를 누르세요. 메뉴를 닫는 순간 적용돼요. (SkyUI와 MCM Helper가 있어야 바꿀 수 있어요. 없으면 F11로 열립니다.)
- 아이템 툴팁 아래에 지금 설정된 키가 "패널 열기/닫기: ○" 로 표시돼요.
- 게임패드 버튼으로는 열 수 없어요. 키보드 키를 쓰세요.
- 반응이 없다면 다른 모드가 F11을 쓰고 있을 수 있어요. 다른 키로 바꾸거나, MCM > 프리즈마 UI > 패널 토글(버튼) 으로 여세요. 같은 페이지의 "Prisma UI 상태 확인"으로 설치 상태도 볼 수 있어요.

■ 제작

- 확인 스크롤: 어픽스가 없는 장비에 1~3개를 붙여요(60% / 30% / 10%).
- 선택 재련(재련 오브 2개): 고른 어픽스 하나만 다시 굴리고 나머지는 그대로 둬요. 횟수 제한이 없어요.
- 슬롯 확장(재련 오브 2개, 다음은 4개): 지금 어픽스를 유지한 채 접미를 하나 더 붙여요.
- 정제(정제 오브 1개, 희귀): 슬롯 수는 그대로 두고 일반 어픽스 전부를 한 번에 다시 굴려요. 6초 안에 두 번 눌러야 확정돼요.
- 교환: 남는 확인 스크롤을 재련 오브(3개 → 1개)나 정제 오브(15개 → 1개)로 바꿀 수 있어요. 한 방향만 돼요.
- 룬워드: 룬 조각을 모아 94종 중 하나를 장비에 변환해요. 확인·재련·정제를 해도 완성된 룬워드는 지워지지 않아요.

■ 재화는 어디서 나오나요

내가 처치하거나 내 소환수가 처치한 적대 대상의 시체에서만 나와요. 상자, 월드, 팔로워가 잡은 적에게서는 나오지 않아요.

- 시체당 기본 확률: 룬 조각 8%, 재련 오브 12%, 확인 스크롤 20%, 정제 오브 2% (모두 MCM에서 조정할 수 있어요)
- 고유·네임드 적은 룬 조각이나 재련 오브 중 하나를 확정으로, 보스와 드래곤은 둘 다 1개씩 확정으로 줘요.
- 천장: 룬 조각은 99번, 재련 오브는 39번 연속으로 안 나오면 다음에 확정이에요. 패널에서 카운터를 볼 수 있어요.

■ 필수·권장 모드

- 필수: SKSE64, Address Library for SKSE Plugins, Prisma UI
- 권장: SkyUI, MCM Helper(설정과 패널 키 변경에 필요), KID


■ 설치와 업데이트

1. 전체 ZIP을 MO2나 Vortex로 설치하고 CalamityAffixes.esp를 켜세요.
2. 업데이트할 때는 예전 버전을 교체하세요. DLL만 따로 바꾸면 안 돼요.
3. 1.x(예전 넥서스 페이지)에서 올라오시는 분은 예전 모드를 끄거나 지워서 칼라미티가 하나만 켜지게 해 주세요. 장비·재화·룬워드는 그대로 이어지고 새 게임은 필요 없어요.


■ 자주 묻는 질문

Q. 패널이 안 열려요.
A. 위의 "패널 여는 법"을 봐 주세요. 대부분 다른 모드가 F11을 쓰고 있거나 Prisma UI가 없는 경우예요.

Q. 툴팁이 안 보여요.
A. Prisma UI가 설치·활성화돼 있는지 확인해 주세요. 로그는 문서/My Games/Skyrim Special Edition/SKSE/CalamityAffixes.log 에 있어요.

Q. 새 게임이 필요한가요?
A. 아니요.

Q. 팔로워나 NPC 장비에도 붙나요?
A. 아니요. 내 장비와, 나·내 소환수가 잡은 적의 드랍이 대상이에요.
