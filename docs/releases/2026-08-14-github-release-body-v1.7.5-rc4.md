# Calamity - Reactive Loot & Affixes v1.7.5-rc4

v1.7.5-rc4는 rc3의 함정 표시, 제작·재련 안전성, 적중 판정을 유지하면서, **Prisma 작업 화면을 사용 빈도가 높은 아이템 어픽스 중심으로 재구성하고 자원·피티 정보와 베이스 선택 경험을 개선한 공개 테스트 빌드**입니다.

베이스 선택 후 실제 작업 대상이 정상적으로 바뀌고, `아이템 어픽스 → 룬워드 → 고급` 순서가 적용되는 것을 인게임에서 확인했습니다. 이번 RC는 UI와 읽기 전용 상태 표시가 중심이며, 전리품 드랍률·피티 기준·어픽스 발동 수치는 변경하지 않았습니다.

## 아이템 어픽스 중심의 작업 화면

- 패널을 열면 가장 자주 사용하는 `아이템 어픽스` 탭이 먼저 표시됩니다.
- 메인 탭과 좌우 키보드 이동 순서는 `아이템 어픽스 → 룬워드 → 고급`으로 통일했습니다. `Home` 키도 아이템 어픽스로 이동합니다.
- 탭 위의 공통 작업 베이스가 룬워드 변환, 재련, 초기화가 실제로 적용될 장비를 한 곳에서 명확히 표시합니다.
- 룬워드 탭은 레시피 탐색과 변환에, 아이템 어픽스 탭은 장착 빌드·현재 어픽스·보호 재련에 집중합니다. 전체 초기화는 고급 탭에 배치했습니다.
- 넓은 화면에서는 패널 전체를 스크롤하는 대신 레시피·효과·보유량처럼 길이가 달라지는 목록만 내부 스크롤합니다.

## 한눈에 보는 룬·재련 자원과 피티

- 룬워드 탭에서 33종 룬의 개별 수량, 보유 종류 수, 총 룬 조각 수를 확인할 수 있습니다.
- 아이템 어픽스 탭에서 현재 재련 오브 수를 확인할 수 있습니다.
- 일반 룬 조각 피티는 `N/99`, 재련 오브 피티는 `N/39`로 표시됩니다.
- 이 수치는 킬 수가 아니라 드랍 확률이 0보다 큰 적격 일반 판정의 연속 실패 횟수입니다. 보장 상태에서는 다음 적격 일반 판정이 보장됩니다.
- 보스·유니크의 별도 보장 보상은 피티를 올리거나 초기화하지 않습니다.

대시보드는 기존 인벤토리와 저장 상태를 2초 패널 갱신으로 읽어 표시할 뿐이며, 드랍 확률·피티 기준·코세이브 형식은 바꾸지 않습니다.

## 스크롤 없는 베이스 선택

- 넓은 화면에서는 패널 폭의 약 60%를 사용하는 3열 선택창으로 현재 착용 후보를 한 번에 펼칩니다.
- 중간 화면은 2열, 좁은 화면은 패널 안쪽 전체 폭의 1열로 반응형 배치됩니다.
- 후보 목록 안쪽 스크롤을 없애고, 선택 행과 장비명 글자를 키웠으며 긴 이름도 생략하지 않습니다.
- 현재 베이스는 체크 표시로 구분합니다.
- 첫 `Esc`는 선택창만 닫고, 정상 선택 뒤에는 베이스 변경 버튼으로 포커스가 돌아갑니다.

## 베이스 선택 버그 수정

Prisma의 포커스 이동 중 `focusout` 처리가 선택창을 실제 클릭보다 먼저 닫아, 다른 장비를 눌러도 작업 베이스가 바뀌지 않을 수 있었습니다. 해당 자동 닫기를 제거해 선택 명령이 정상 전달되도록 수정했습니다.

바깥 클릭, `Esc`, 탭 전환, 패널 닫기와 정상 선택 후 닫기는 그대로 유지합니다.

## 검증 범위

- **인게임:** 다른 장비 선택 시 실제 작업 베이스 변경, 아이템 어픽스 우선 탭 순서 및 패널 표시를 확인했습니다.
- **자동 검증:** Prisma 22개 참조 자산의 폐쇄성, 실제 HTML 순서의 classic script 실행, 레시피·베이스 선택 UI 동작, 반응형 레이아웃과 자원·피티 표시 계약을 검사합니다.

## Compatibility / 설치

- 기존 세이브와 호환되며 새 게임이 필요하지 않습니다.
- rc3의 ESP FormID와 코세이브 wire format을 유지합니다.
- 전리품 드랍률, 피티 기준, 어픽스 발동 확률과 피해 수치는 변경하지 않았습니다.
- 자원·피티 대시보드는 읽기 전용입니다.
- MO2에서는 이전 버전에 **Merge가 아니라 Replace**로 설치하세요.
