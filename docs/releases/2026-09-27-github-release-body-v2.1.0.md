# Calamity - Reactive Loot & Affixes v2.1.0

v2.1.0은 남는 **확인 스크롤을 재련 오브·정제 오브로 바꾸는 교환**을 추가한 릴리스입니다. ESP와 코세이브는 2.0.x와 같습니다. 2.0의 제작 흐름 전체는 [2.0.0 릴리스 노트](https://github.com/servaltullius/calamity-reactive-loot-affixes/blob/main/docs/releases/2026-09-26-github-release-body-v2.0.0.md)를 확인하세요.

## 확인 스크롤 교환

| 교환 | 비용 |
| --- | ---: |
| 재련 오브 1개 | 확인 스크롤 3개 |
| 정제 오브 1개 | 확인 스크롤 15개 |

- 2.0부터 정제는 슬롯 수를 유지한 채 다시 굴리기 때문에, 장비를 한 번 확인하면 확인 스크롤을 다시 쓸 일이 없습니다. 드랍률이 가장 높은 스크롤만 쌓이던 문제를 교환으로 해결합니다.
- 패널 "제작 재료"의 세 재화 카드 아래에서 교환합니다. 스크롤이 모자란 쪽 버튼은 꺼지고, 장비를 선택하지 않아도 쓸 수 있습니다.
- **한 방향만 가능하며 되돌릴 수 없습니다.** 비율은 고정입니다. 3:1은 드랍률(스크롤 20%, 재련 오브 12%) 비율에 교환 손실을 조금 얹은 값이고, 15:1은 정제 오브 1개를 재련 오브 약 5개 가치로 본 값입니다.
- 교환은 제작과 같은 방식으로 스크롤이 정확히 비용만큼 줄었는지, 오브가 정확히 1개 들어왔는지 확인하고 어긋나면 스크롤을 돌려줍니다. 제작이 진행 중일 때는 교환하지 않고, 버튼을 연타해도 한 번만 처리합니다.

## 확인한 범위

- 2026-09-27 사용자가 인게임에서 교환을 확인했습니다.
- 교환 비율·재화 정적 검사, 패널 버튼 상태·연타 차단·구버전 DLL 대응 테스트, 교환 안전 순서 검사를 추가했습니다. Python·생성기·SKSE 검사와 배포 패키지 검증을 통과했습니다.
- 패널 레이아웃 점검(108개 조합: 크기 × 언어 × 접힘 상태 × 탭)에서 잘림·스크롤 문제 0건입니다.

## 설치와 업데이트

1. **`CalamityAffixes_MO2_v2.1.0_2026-09-27.zip`** 전체를 설치합니다. DLL이 바뀌었으므로 DLL만 따로 두지 말고 MO2에서 기존 Calamity 모드를 **Replace**하세요.
2. 새 게임은 필요하지 않습니다. 1.x에서 올라오는 경우의 안내는 2.0.0 노트와 같습니다.

Prisma UI는 이 ZIP에 포함되지 않습니다. 공개 자산은 **MO2 ZIP, ZIP SHA256, DLL, ESP** 네 개입니다.
