# Calamity - Reactive Loot & Affixes v1.7.5-rc1

v1.7.5-rc1은 **함정이 실제 바닐라 물체로 보이고, 곰덫이 열리고 닫히는 첫 공개 테스트 빌드**입니다.

함정 6종의 지속 마커를 임시 파티클 글리프에서 스크립트 없는 바닐라 물리 모델로 전환했습니다. 곰덫 외 범위 함정은 주변 모두에게 엔진 광역 효과를 뿌리지 않고, 런타임이 반경 안의 적대 대상만 골라 최대 2명에게 적용합니다. 시체 폭발 대상 수명과 저장·장착 효과 재계산 회귀 안전망도 함께 보강했습니다. **기존 세이브와 호환되며 새 게임이 필요하지 않습니다.**

## 함정 6종이 바닐라 물체로 보입니다

- 곰덫: 바닐라 금속 곰덫
- 룬 함정: 석재 압력판
- 역병 포자: 독거미 주머니
- 역청 황폐: 기름 웅덩이
- 흡수 포자: 흰거미 알
- 혼돈의 룬: 금속 압력판

원본 액티베이터나 피해 스크립트를 소환하지 않습니다. Calamity 소유 `MSTT`가 모델 경로만 참조하며, 런타임이 비영속 월드 레퍼런스로 배치하고 활성화·충돌을 차단합니다. 기존의 짧은 무장·발동·자연 만료 파티클과 음향은 상태 피드백으로 유지됩니다.

여섯 모델의 지면 배치와 육안 가시성은 인게임에서 확인했습니다.

## 곰덫 애니메이션 복원

곰덫 표시물은 더 이상 닫힌 기본 자세로만 생성되지 않습니다.

- 생성 시 `StartOpen`으로 열림
- 최초 발동 직전 `Trigger01`로 닫힘
- 재장전 시 `Reset01`로 다시 열림
- 열림 이벤트가 수락된 뒤 900ms 동안 발동을 막아 애니메이션이 끝나기 전에 닫히는 현상 방지

행동 그래프 로딩이 늦으면 250ms 간격으로 최대 8회만 재시도하며, 끝내 준비되지 않아도 게임플레이 발동은 계속됩니다. 곰덫의 설치·발동과 열림/닫힘 애니메이션은 인게임에서 확인했습니다.

## 범위 함정은 적대 대상에게만 적용

곰덫 외 5종의 주문 레코드는 `Effect.Area=0`을 사용하고, 함정 런타임이 설정 반경 안의 적대 대상만 직접 선택합니다.

- 발동당 최대 2명
- 기존 피해·감속·저주 수치와 지속시간 유지
- 주 주문과 보조 주문을 함께 쓰는 함정은 두 주문분의 틱 예산을 원자적으로 예약
- 예산 경계에서 감속만 걸리고 방어 저하·흡수·저주가 빠지는 반쪽 발동 방지

## 안정성과 회귀 안전망

- 시체 폭발의 다중 대상 목록이 전체 시전 루프 동안 `NiPointer<Actor>` 강한 참조를 유지해, 앞선 주문의 엔진 재진입으로 뒤쪽 대상 참조가 무효화될 위험을 막았습니다. 거리 정렬·대상 상한·피해량은 바뀌지 않습니다.
- 실제 저장 경로가 사용하는 공용 writer를 추출하고, 현재 코세이브 레코드 8종의 타입·버전·순서·scalar 폭·바이트 배열을 golden test로 고정했습니다. 코세이브 wire format 자체는 변경하지 않았습니다.
- 장착 효과 재계산의 접미사 우선순위, 패시브 주문 조정, prefix family 중복 배제를 production policy 행동 테스트로 고정했습니다. 문장 단위 source pin은 37개 줄였고 전체 상한도 353개에서 316개로 낮췄습니다.

## Compatibility

- 기존 코세이브 직렬화 형식은 변경하지 않았으며 기존 세이브를 그대로 사용할 수 있습니다.
- 기존 ESP FormID는 유지하고 새 함정 표시용 `MSTT`만 append-only로 추가했습니다.
- 함정 주문의 적대 대상 선택 방식은 의도된 동작 변경입니다. 기존 피해·감속·저주 수치와 지속시간은 유지됩니다.
- MO2에서는 이전 버전에 **Merge가 아니라 Replace**로 설치하세요.
