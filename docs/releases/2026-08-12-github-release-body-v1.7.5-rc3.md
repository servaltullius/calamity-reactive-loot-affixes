# Calamity - Reactive Loot & Affixes v1.7.5-rc3

v1.7.5-rc3는 rc2의 바닐라 함정 표시와 곰덫 애니메이션을 유지하면서, **룬워드 제작·재련 안전성, 장착 빌드 가시성, 활·석궁 및 소환물 적중 판정**을 보강한 공개 테스트 빌드입니다.

최신 종합 테스트 빌드의 기본 인게임 동작과 패널 표시가 정상임을 사용자 확인했습니다. rc2에서 확인한 함정 6종 표시, 곰덫 열림·발동·재장전 애니메이션, 표시물 자동 정리 경로는 rc3에서 변경하지 않았습니다. 아래의 자원·적중 경계는 자동 테스트와 코드리뷰로 검증했으며, 장시간 전투·셀 전환·저장/불러오기와 동료·중립 보호는 계속 회귀 확인 대상입니다.

## 목표를 유지하는 재련

- 일반 재련은 기존처럼 재련 오브 1개를 사용합니다.
- 보호 재련은 오브 2개를 사용해 선택한 일반 접두 또는 접미 하나를 유지하고 나머지만 다시 굴립니다.
- 현재 일반 어픽스 개수와 완성 룬워드를 보존합니다. 보호한 어픽스의 진화·모드 상태도 유지합니다.
- 베이스를 바꾼 뒤 남은 오래된 UI 선택은 비용이나 RNG 상태를 바꾸기 전에 서버가 거부합니다.
- 기존 2·3옵션 장비가 재련 후 1옵션으로 줄어들던 문제를 수정했습니다. 일반 어픽스가 없는 베이스만 최소 1개를 얻습니다.

## 룬워드 자원 안전성과 재료 탐색

- 이미 같은 룬워드가 완성된 장비에 동일 레시피를 다시 적용하면 조각 계산·소비 전에 차단합니다. 패널도 해당 레시피를 `완료`로 표시합니다.
- 다른 룬워드로 명시적으로 교체하는 기존 흐름과 실패 시 롤백은 유지합니다.
- 레시피 탐색기에 `룬 조각 준비`와 `1개 부족` 필터, 레시피별 현재 보유 진행을 추가했습니다.
- 같은 룬이 여러 번 필요한 레시피는 요구량을 합산하며, 재료 필터는 베이스 유형 및 검색 조건과 함께 적용됩니다.

재료 표시는 **전체 레시피 요구량과 현재 인벤토리의 룬 조각을 비교하는 읽기 전용 정보**입니다. 이미 삽입한 진행, 선택 베이스의 호환성, 실제 변환 가능 여부를 뜻하지 않습니다.

## 현재 장착 빌드 요약

Prisma의 `아이템 어픽스` 탭에서 장착 효과를 다음 네 그룹으로 확인할 수 있습니다.

- 공격 발동
- 피격·생존
- 처치
- 패시브

현재 장비 보정이 반영된 조건 충족 시 1회 판정률, 별도 Lucky Hit 관문, 장착 개수, 접두·접미·룬워드 구분을 표시합니다. 동일 발동 어픽스는 장착 개수와 무관하게 한 번의 판정을 공유하며, 단계형 접미는 최고 티어와 억제된 하위 티어를 구분합니다. ICD, 대상별 제한, 예산, 추가 조건까지 합산한 실전 초당 발동률을 뜻하지는 않습니다.

## 활·석궁과 소환물 적중 판정

- 화살·볼트의 `HitData.weapon`이 비어 있어도 실제 투사체의 활·석궁 `weaponSource` 또는 현재 원거리 공격 데이터가 확인되면 치명 시전 판정을 진행합니다.
- 주문 적중과 단순 장착 무기 fallback은 계속 거부해 발동 주문의 재귀 시전을 막습니다.
- 플레이어 소환물의 주문 적중이 플레이어가 장착한 무기 때문에 함정의 `weapon hit`으로 오인되던 경로를 차단했습니다.
- 실제 플레이어 근접·활·석궁 적중은 기존처럼 허용합니다.

## 검증 범위

- **코드리뷰:** rc2 이후 4개 커밋의 룬워드 소비·재련 원자성, 적중 출처 수명, Prisma 상태·캐시·64비트 토큰 경계를 독립 검토했으며 RC 차단급 문제를 발견하지 않았습니다.
- **자동 검증:** C++ 플러그인 빌드와 정적/호스트 런타임 게이트, 전체 Python 도구 테스트, .NET 생성기 테스트, Prisma Node 동작 테스트, 문서·핀·버전 검사, MO2 ZIP 구조·DLL 해시·CRC·버전 검사를 통과했습니다.
- **인게임:** 최신 종합 테스트 빌드의 기본 동작과 패널 표시가 정상임을 확인했습니다. 개별 자원 실패 복구와 모든 적중 출처 조합을 전부 확인했다는 의미는 아닙니다.

## Compatibility / 설치

- 기존 세이브와 호환되며 새 게임이 필요하지 않습니다.
- ESP FormID와 코세이브 wire format은 변경하지 않았습니다.
- 전리품 드롭률과 발동 확률은 변경하지 않았습니다.
- 보호 재련의 오브 2개 비용과 기존 일반 어픽스 개수 보존은 의도된 동작 변경입니다.
- 장착 빌드 요약과 룬 보유 진행 표시는 읽기 전용입니다.
- MO2에서는 이전 버전에 **Merge가 아니라 Replace**로 설치하세요.
