# Calamity - Reactive Loot & Affixes v1.7.5-rc5

v1.7.5-rc5는 rc4의 어픽스 중심 Prisma 작업 화면과 자원·피티 대시보드를 유지하면서, **새 장비에서도 일반 어픽스를 실제로 3슬롯까지 성장시킬 수 있는 정식 진행 경로**와 **드래곤 처치 확정 보상**을 추가한 공개 테스트 빌드입니다.

이번 RC의 핵심은 새로운 효과 수를 늘리는 것이 아니라, 첫 어픽스 이후에도 플레이어가 재련 오브를 사용해 `접두 1 + 접미 2` 구성을 단계적으로 완성할 수 있게 만든 것입니다. 슬롯 확장과 드래곤 보상은 모두 인게임에서 확인했습니다.

## 일반 어픽스 1→2→3슬롯 진행

- 일반 어픽스가 없는 베이스는 기존과 동일하게 **일반 재련 1회, 재련 오브 1개**로 첫 어픽스를 얻습니다.
- 일반 어픽스가 1개인 베이스는 **재련 오브 2개**로 두 번째 슬롯을 엽니다.
- 일반 어픽스가 2개인 베이스는 **재련 오브 4개**로 세 번째 슬롯을 엽니다.
- 슬롯 구조는 `접두 → 접미 1 → 접미 2`이며, 세 번째 슬롯은 이미 붙은 접미와 다른 계열에서 선택됩니다.
- 확장은 기존 일반 어픽스를 다시 굴리지 않습니다. 완성된 룬워드와 기존 어픽스의 런타임 상태도 그대로 유지합니다.
- 최대 일반 어픽스 수는 3개이며, 완성 룬워드는 별도 슬롯으로 계속 보존됩니다.

이 경로로 신규 플레이에서도 접미 어픽스, 2·3옵션 조합, 2옵션 이상에서 사용하는 보호 재련에 정상적으로 도달할 수 있습니다.

## Prisma 슬롯 진행 UI

- 아이템 어픽스 탭에 `접두 · 접미 1 · 접미 2` 진행도를 표시합니다.
- 다음 슬롯 번호, 필요한 재련 오브, 현재 보유량과 서버가 판단한 사용 가능 상태를 함께 보여줍니다.
- 첫 어픽스 필요, 오브 부족, 최대 슬롯, 잘못된 슬롯 구성, 접미 슬롯 비활성화 등 확장 불가 이유를 구분해 안내합니다.
- 확장 요청 중에는 재련·룬워드 변환을 포함한 다른 장비 변이 버튼을 잠가 한 번에 하나의 변경만 처리합니다.

## 슬롯 확장의 자원·상태 안전성

- 요청에는 선택 베이스의 64비트 인스턴스 키와 예상 일반 어픽스 개수를 함께 보내며, 서버가 둘 다 다시 검증합니다.
- 빠른 이중 클릭, 장비 교체, 슬롯 수 변경, 다른 변환 진행 중 요청은 비용을 쓰기 전에 거부합니다.
- 유효한 다른 계열 접미 후보를 먼저 확정한 뒤 오브를 차감합니다.
- 오브가 정확한 수량만큼 빠졌는지 실제 인벤토리 차이로 확인합니다.
- 차감 뒤 베이스나 슬롯 상태가 바뀌면 관측된 소비량을 환불하고, 접미 셔플 백과 RNG 상태도 가능한 범위에서 복구합니다.
- 기존 룬워드 primary, 일반 어픽스 토큰과 런타임 상태는 삭제하지 않고 새 접미 상태만 추가합니다.

## 드래곤 처치 확정 보상

- `ActorTypeDragon` 키워드를 가진 적격 적대 드래곤은 `LocRefTypeBoss` 지정 여부와 관계없이 보스 보상 등급으로 처리합니다.
- 플레이어 또는 플레이어 소유 소환물·프록시가 처치하면 드래곤 시체에 **룬 조각 1개와 재련 오브 1개**를 각각 넣습니다.
- 보상은 플레이어 인벤토리에 직접 지급하거나 월드에 생성하지 않으며, 기존과 동일하게 시체에서 획득합니다.
- 이미 해당 통화가 들어 있는 전환 시체와 같은 시체의 재처리는 카테고리별 중복 방지 규칙을 따릅니다.
- 드래곤 확정 보상은 일반 적의 8%/12% 판정을 추가 실행하지 않고, 일반 룬·오브 피티를 증가시키거나 초기화하지 않습니다.

## 검증 범위

- **인게임:** 일반 어픽스 `1→2→3` 확장과 기존 어픽스·완성 룬워드 보존, 드래곤 시체의 룬 조각·재련 오브 각 1개 지급을 확인했습니다.
- **자동 검증:** Python 도구 테스트 183개, Generator 테스트 152개, SKSE CTest 2개를 통과했습니다.
- **UI 검증:** 실제 `index.html`의 classic script 순서로 슬롯 진행 표시, 비용·불가 사유, 64비트 키 명령, pending 중복 클릭과 변이 버튼 잠금을 검사합니다.
- **패키지 검증:** Papyrus 3종을 다시 컴파일하고, MO2 ZIP 구조·CRC·정확한 PEX 집합·DLL 해시·패키지 버전을 확인합니다.

## Compatibility / 설치

- 기존 세이브와 호환되며 새 게임이 필요하지 않습니다.
- ESP FormID와 코세이브 wire format은 변경하지 않았습니다.
- 기존 장비의 일반 어픽스 수, 완성 룬워드와 런타임 상태는 그대로 유지됩니다.
- `1→2` 오브 2개, `2→3` 오브 4개는 의도된 신규 성장 비용입니다.
- MO2에서는 이전 버전에 **Merge가 아니라 Replace**로 설치하세요.
