## 3. 변경 이력 (Changelogs 탭)

새 페이지의 첫 버전이 2.1.2이므로 2.0.0부터 한꺼번에 적는다. 버전마다 아래 줄을 넣는다.

```text
2.1.2
- Every runeword now shows one full name in tooltips, the panel, and active effects. Seven names had lost all but their first word ("Runeword Holy" is now "Runeword Holy Thunder"), Korean tooltips now use the panel list's names, and effect names spell out CTA, CoH, HOTO, and BotD.
- 룬워드 이름을 툴팁·패널·마법 효과 창에서 하나로 통일했습니다(잘린 이름 7개, 목록과 다르던 한국어 이름 37개, 효과 이름 줄임말).

2.1.1
- The Selected Base Affixes box no longer hides the other affixes behind a long first one.
- 선택 베이스 어픽스 상자에서 첫 어픽스가 길면 나머지가 가려지던 문제를 고쳤습니다.

2.1.0
- Trade spare Identify Scrolls one way: 3 for a Reforge Orb, 15 for a Scouring Orb.
- 남는 확인 스크롤을 재련 오브(3개)나 정제 오브(15개)로 바꿀 수 있습니다(한 방향).

2.0.1
- Crafting dashboard counts line up, and rune grid labels are no longer cut off.
- 제작 재료 대시보드 정렬과 룬 그리드 칸 문구 잘림을 고쳤습니다.

2.0.0
- Crafting reworked: Identify Scroll (1-3 affixes), Reforge (one chosen affix, 2 Reforge Orbs), Scouring Orb (reroll every affix, keep the slots).
- New currencies drop from hostile corpses: Identify Scroll 20%, Scouring Orb 2% (adjustable in MCM).
- Crafting dashboard in the panel, and panel layout fixes at wide and small sizes.
- Everything since the old page's 1.2.21: corpse-only currency drops, slot expansion, trap markers, summon friendly-fire protection, combat freeze fixes, and more (full list on GitHub).
- 제작을 확인 스크롤(1~3개 부여) · 선택 재련(어픽스 하나 교체) · 정제 오브(전체 리롤)로 개편했습니다.
- 새 재화 2종이 적 시체에서 나옵니다(확인 20%, 정제 2%, MCM에서 조정).
- 제작 재료 대시보드와 넓은·작은 패널의 표시 잘림 수정, 구 페이지 1.2.21 이후 반년 치 개선(GitHub CHANGELOG)이 들어 있습니다.
```

## 6. 고정 댓글 (Sticky)

사람들이 가장 많이 헷갈리는 **패널 단축키** 안내다. 페이지를 연 직후 올리고 고정한다.

```bbcode
[b]Can't open the panel? / 패널이 안 열리나요?[/b]
[list]
[*]Default key is [b]F11[/b]. Change it: ESC > System > Mod Configuration > Calamity Affixes > Hotkey & Debug > Toggle Calamity Panel. It works once you close the menu (needs SkyUI + MCM Helper).
[*]The current key is shown at the bottom of the Calamity item tooltip. Gamepad buttons can't open it.
[*]Still nothing: MCM > Prisma UI > Toggle Panel (Button), then Check Prisma UI Status. Prisma UI is required.
[/list]
[list]
[*]기본 키는 [b]F11[/b]입니다. 변경: ESC > 시스템 > 모드 설정 > Calamity Affixes > 단축키·디버그 > 칼래미티 패널 토글. 메뉴를 닫으면 적용됩니다(SkyUI + MCM Helper 필요).
[*]Calamity 아이템 툴팁 아래에 현재 키가 표시됩니다. 게임패드 버튼으로는 열 수 없습니다.
[*]그래도 안 되면 MCM > 프리즈마 UI > 패널 토글(버튼), 이어서 Prisma UI 상태 확인. Prisma UI는 필수입니다.
[/list]
```

댓글에 답할 때 참고할 단축키 사실관계(코드 기준):

- 기본 키는 `F11`이다. MCM에 키를 지정하지 않았으면 이 키로 열린다.
- 월드와 인벤토리 어디서든 열린다. 메인 메뉴·로딩 화면·캐릭터 생성 중에는 열리지 않는다.
- 게임패드 버튼으로는 열 수 없다. 키보드 키를 써야 한다.
- MCM `Calamity Affixes › Hotkey & Debug › Toggle Calamity Panel`에서 바꾼다. MCM(저널 메뉴)을 닫는 순간 새 키가 적용된다.
- 키를 바꾸려면 SkyUI와 MCM Helper가 필요하다. 둘이 없으면 F11로 열린다.
- Calamity 아이템 툴팁 아래에 현재 키가 `Open/Close Panel: <키>`(한국어 UI는 `패널 열기/닫기: <키>`)로 표시된다.
- 단축키가 먹지 않으면 MCM `Prisma UI › Toggle Panel (Button)`으로 바로 열 수 있고, 같은 페이지의 `Check Prisma UI Status`로 Prisma UI 상태를 확인한다.

## 7. 옛 페이지 은퇴
