# Calamity - Reactive Loot & Affixes v2.1.4-rc1

2.1.4-rc1은 게임 안 한국어 표기를 "칼라미티"로 통일한 공개 테스트 빌드입니다. 게임 동작, ESP, 코세이브, 게임 데이터는 [2.1.3](https://github.com/servaltullius/calamity-reactive-loot-affixes/releases/tag/v2.1.3)과 같습니다. 정식 버전은 계속 v2.1.3입니다.

## 바뀐 점

- 한국어 UI의 모드 이름을 "칼래미티"에서 "칼라미티"로 바꿨습니다. 12곳입니다.
  - MCM: 단축키 이름 "칼라미티 패널 토글"과 도움말, 단축키 등록 이름
  - 패널: 제목 "칼라미티 조작", 장착 빌드 안내 문구, 화면 읽기용 라벨
- 글자 수가 같아 패널 배치는 바뀌지 않습니다. 영어 UI는 그대로입니다.

## 확인한 범위

- Python·생성기·SKSE 검사, 패널 스크립트·뷰 구조 검사와 배포 패키지 검증을 통과했습니다.
- 표시 문자열만 바뀐 빌드라 인게임 확인은 이 테스트 빌드로 진행합니다. MCM의 단축키 메뉴 이름과 패널 제목이 "칼라미티"로 보이는지 확인해 주세요.

## 설치

1. **`CalamityAffixes_MO2_v2.1.4-rc1_2026-09-27.zip`** 전체를 설치하고, MO2에서 기존 Calamity 모드를 **Replace**하세요.
2. 새 게임은 필요하지 않습니다.

Prisma UI는 이 ZIP에 포함되지 않습니다. 공개 자산은 **MO2 ZIP, ZIP SHA256, DLL, ESP** 네 개입니다.
