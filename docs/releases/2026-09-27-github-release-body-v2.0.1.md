# Calamity - Reactive Loot & Affixes v2.0.1

v2.0.1은 2.0.0의 패널 표시를 다듬은 업데이트입니다. 게임 동작, ESP, 코세이브는 2.0.0과 같습니다. 확인 스크롤·선택 재련·정제 오브로 바뀐 제작 흐름 전체는 [2.0.0 릴리스 노트](https://github.com/servaltullius/calamity-reactive-loot-affixes/blob/main/docs/releases/2026-09-26-github-release-body-v2.0.0.md)를 확인하세요.

## 고친 점

- **제작 재료 대시보드:** 세 재화 카드가 피티 카드와 한 줄을 나눠 쓰느라 좁아서, 라벨이 서로 다른 줄 수로 넘어가며 숫자 높이가 어긋나고 "Reforge · expand" 설명이 잘렸습니다. 피티 카드를 아래 줄로 내리고 숫자·설명을 카드 아래쪽에 맞춰 정렬합니다.
- **룬 그리드 칸:** 영어·이중 표기에서 "Rune (Missing)", "Owned: 1/1"이 잘렸습니다. 칸에는 한 언어의 짧은 문구("Missing"/"부족")와 `보유/필요` 수량(예: `12/1`)만 보여주고, 전체 이중 표기는 마우스를 올리면 나옵니다. 한국어 글꼴의 줄 높이 때문에 룬 이름이 밀려나던 문제도 고쳤습니다.
- **이중 표기 모드(기본값):** 대시보드 설명도 한 언어로 표시하고 전체 문구는 마우스 오버로 보여줍니다.

## 확인한 범위

- Chromium으로 6가지 패널 크기 × 영어·한국어·이중 표기에서 대시보드 숫자 정렬과 룬 칸·설명 잘림을 측정해 모두 문제가 없음을 확인했습니다. 가장 긴 룬 이름과 세 자리 보유 수량도 칸 안에 들어갑니다.
- 전체 패널 레이아웃 점검(108개 조합: 크기 × 언어 × 접힘 상태 × 탭)에서 잘림·스크롤 문제 0건입니다.
- 패널 스크립트·CSS 계약 테스트를 추가했고, Python·생성기·SKSE 검사와 배포 패키지 검증을 통과했습니다. 게임 로직 변경이 없어 인게임 동작은 2.0.0 확인 결과를 그대로 따릅니다.

## 설치와 업데이트

1. **`CalamityAffixes_MO2_v2.0.1_2026-09-27.zip`** 전체를 설치합니다. MO2에서는 기존 Calamity 모드를 **Replace**하세요.
2. 1.x에서 올라오는 경우의 안내(확인 스크롤로 첫 어픽스 부여, 이전 모드 비활성화, 넥서스 1.2.21에서의 변경 사항)는 2.0.0 노트와 같습니다.
3. 새 게임은 필요하지 않습니다.

Prisma UI는 이 ZIP에 포함되지 않습니다. 공개 자산은 **MO2 ZIP, ZIP SHA256, DLL, ESP** 네 개입니다.
