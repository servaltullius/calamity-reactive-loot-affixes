# Calamity - Reactive Loot & Affixes v1.7.4-rc1

v1.7.4-rc1은 **"발동이 보이고 들리는" 릴리스의 첫 공개 테스트 빌드**입니다.

커스텀 발동 이펙트가 게임에서 전혀 렌더되지 않던 ESP 계약 결함을 실측 기반으로 수리했고, 모든 CastSpell 계열 발동에 시청각 피드백을 부여했으며, 다중 어픽스 발동 페널티를 "실제 발동 가능한 어픽스 수" 기준으로 재정의했습니다. v1.7.3의 안정성 수정은 모두 포함됩니다. **기존 세이브와 호환되며 새 게임이 필요하지 않습니다.**

## 발동 이펙트가 실제로 보입니다

커스텀 발동 이펙트(ARTO) 26종 전부가 지금까지 화면에 렌더되지 않았습니다. 원인은 두 겹이었습니다.

- 모델 경로가 `Meshes\` 접두사를 달고 있어 엔진이 `Data\Meshes\Meshes\...`를 찾았고(소리 없는 로드 실패),
- 레코드 타입(DNAM)이 게임 규약과 어긋난 raw 값으로 직렬화되어 있었습니다.

Skyrim.esm의 ARTO 201개를 실측해 규약을 확정하고, 생성기가 올바른 경로·raw 값을 강제하며, 저장된 ESP 바이트를 직접 검사하는 회귀 테스트로 고정했습니다. 룬워드 꿈의 타격 아트는 월드 폭발용 NIF에서 바닐라 액터 부착 전격 아트로 교체했습니다.

## 모든 발동 효과에 시청각 피드백

CastSpell 계열 발동 105종(코어 34, 룬워드 71)에 테마별 피드백을 추가했습니다.

- 원소 타격: 해당 원소 cloak 아트 (화염/냉기/전격)
- 흡수류: 색상 규약 흡수 아트 (적=생명력, 녹=기력, 청=매지카)
- 정신 계열: 일루전 바디 아트, 소환: 소환 아트 + 소환음
- 물리 피해 전환(주입) 3종과 아크메이지에 원소별 히트 사운드 (SNDD On Hit)
- 함정 6종이 장전 완료 시 곰덫 재장전 클릭음을 재생 — 마커를 못 봐도 귀로 인지 가능

모든 아트·사운드는 Skyrim.esm에서 실측 검증된 바닐라 자산만 사용합니다. 새 어픽스가 피드백 없이 추가되는 것은 이제 빌드 단계에서 차단됩니다.

## 발동 페널티 재정의 (밸런스 상향)

다중 어픽스 발동 페널티(Best Slot Wins)가 "아이템의 전체 효과 수"가 아니라 **"실제로 발동 가능한 어픽스 수"**를 셉니다.

- 패시브 접미사·발동 불가 어픽스가 같은 아이템의 발동 확률을 더는 깎지 않습니다.
- 예: 발동 어픽스 1개 + 패시브 3개 구성은 이전 ×0.5에서 **×1.0(페널티 없음)**으로.
- 룬워드 완성 아이템이 대표적인 수혜 대상입니다 (예: 꿈 15% → 24~30%).
- 아이템 툴팁이 기본 발동률과 현재 유효 발동률을 함께 표시합니다.

## Prisma 패널 UX 개선

- **MCM 단축키 즉시 반영**: 신규 설치 후 단축키를 바꿔도 수동으로 패널을 한 번 열어야 작동하던 문제 수정 — 저널(MCM)을 닫는 순간 반영됩니다.
- **아이템 어픽스 탭**: 선택된 룬워드 베이스의 어픽스를 즉시 표시, 빈 화면 안내를 절차형으로 교체.
- **검토 영역 분리**: "선택 베이스 어픽스"와 "선택 레시피 미리보기"가 각각의 접이식 박스로 분리되어 스크롤 없이 둘 다 읽힙니다.
- **레시피 미리보기 한글화**: 개발용 레코드명 노출을 제거하고 언어 설정에 맞는 표시명을 사용합니다.
- 디버그 도구는 디버그 토글이 켜진 경우에만 표시, 부족 룬조각 안내 중복 정리, 베이스 별표(*) 범례, 수동 모드 설명, 엔진 상태 문구 한글화.

## 진단·포렌식 인프라

- 릴리스 DLL이 PDB와 함께 빌드·보관되어 크래시 로그의 `Module+Offset`을 함수 단위로 역추적할 수 있습니다.
- 상세 로깅 세션은 5초 주기로 flush되어 프리징·강제 종료에도 로그 꼬리가 보존됩니다.
- 발동 파이프라인 관찰 로그(효과 적용 이벤트, 피드백 수락 결과)와 로그 자동 점검 도구가 추가됐습니다.

## 호환성

- 코세이브 직렬화 형식과 ESP FormID는 변경되지 않았습니다. 기존 세이브 그대로 사용 가능합니다.
- 발동 페널티 재정의와 피드백 추가는 의도된 체감 변경입니다. 장비 구성에 따라 발동 빈도가 올라갑니다.
- MO2에서 이전 버전에 **Merge가 아니라 Replace**로 설치하세요.

## 이 rc에서 피드백을 구하는 것

- 발동 이펙트·사운드의 체감 (과다/부족, 특정 어픽스의 어색한 테마)
- 발동 빈도 체감 (페널티 재정의 이후)
- 함정 마커·장전음 시인성
- Prisma 패널 사용감
