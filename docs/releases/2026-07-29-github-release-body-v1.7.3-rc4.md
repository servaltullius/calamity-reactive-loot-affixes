# Calamity - Reactive Loot & Affixes v1.7.3-rc4

rc4는 **rc3 이후 확인된 효과 설명/실동작 불일치와 MCM·룬워드 재련·런타임 상태 관리 문제를 수정한 교체 프리릴리스**입니다.

rc3의 Prisma 패널 초기화 수정과 v1.7.3의 안정성 수정 3건(CTD 2건, 어픽스 발동이 영구히 멈추는 문제 1건)은 모두 포함됩니다.

## 효과 설명과 실동작 일치

### 고정 피해 + 비율 피해

다음 5개 효과가 설명의 고정 피해를 빠뜨리고 비율 피해만 적용하던 문제를 수정했습니다.

- Storm Call: `10 + 물리 타격 피해의 10%`
- Flame Strike: `6 + 물리 타격 피해의 10%`
- Frost Strike: `6 + 물리 타격 피해의 10%`
- Spark Strike: `6 + 물리 타격 피해의 10%`
- Ember Brand: `4 + 물리 타격 피해의 4%`를 4초 동안 적용

### Crit Cast 7종

- 근접 무기는 치명타 또는 강공격 적중에서 판정합니다.
- 활·석궁은 강공격이 없으므로 모든 적중에서 판정하는 기존 의도를 설명에 명시했습니다.
- 피해량은 주문의 **즉시 적용 직접 원소 생명력 피해**와 물리 타격 피해의 `30%` 중 큰 값입니다.
- 유틸리티 수치나 조건부 분해 효과처럼 실제 직접 피해가 아닌 더 큰 수치를 잘못 선택하지 않습니다.

## 룬워드·MCM 수정

- 완성 룬워드에 재련을 사용해도 일반 어픽스만 다시 굴립니다.
- 룬워드 토큰과 Grief 진화 XP, Infinity 모드 상태를 보존합니다.
- 재련 오브가 정확히 1개 소모됐는지 확인하며, 예상 밖의 소모량이면 가능한 범위에서 1개를 복구하고 실패로 처리합니다.
- Prisma 패널의 안내와 호환성 메시지도 이 동작과 같은 문구를 사용합니다.
- ESL로 로드된 플러그인의 MCM 퀘스트를 잘못된 전체 `FE...` FormID로 조회할 수 있던 문제를 수정했습니다. light 플러그인 로컬 FormID의 하위 12비트를 사용하므로 기존 세이브에서도 MCM 등록 경로를 다시 찾을 수 있습니다.

## 런타임 안정성

- 실패 가능한 주문·함정·시체 효과 준비를 마친 뒤에만 확률, 발동 예산, ICD, XP와 상태를 확정합니다.
- 저장/불러오기 전 세대에서 대기 중이던 비동기 피해 작업은 새 세션 상태에 적용하지 않습니다.
- MCM에서 기능을 끄더라도 이미 확정된 변환 피해는 취소하지 않습니다.
- 유효한 활성 함정과 셀이 있을 때만 함정 작업을 큐에 넣으며, 잘못된 셀 때문에 기존 함정을 먼저 제거하지 않습니다.
- EventBridge의 참조 별칭 14개를 제거하고 트리거 캐시 소유권을 상태 그룹으로 이동했습니다. 런타임 활성 상태는 원자적으로 관리합니다.

## 생성·릴리스 안전성

- 어픽스 action 스키마가 실제 런타임 계약에 없는 필드와 잘못된 조합을 거부합니다.
- source/generated 어픽스 JSON을 정확히 대조하고 KID/SPID 산출물을 타임스탬프 없는 결정적 출력으로 생성합니다.
- GitHub 릴리스는 실제 DLL 빌드 뒤 Prisma·런타임 검증과 compiler-less Papyrus 패키징 E2E까지 모두 통과해야 게시됩니다.

## 호환성

- 새 게임은 필요하지 않습니다.
- 코세이브 직렬화 형식, MCM 옵션, ESP 레코드와 드랍 확률은 변경하지 않았습니다.
- 기존 장비와 완성 룬워드는 그대로 로드됩니다.
- 위 5개 타격 피해 효과와 7개 Crit Cast의 설명·피해 선택 계약은 의도적으로 변경됐습니다.

## 인게임 확인 요청

1. 기존 세이브와 새 게임에서 MCM이 등록되고 설정·패널 버튼이 동작하는지
2. Storm Call, Flame/Frost/Spark Strike, Ember Brand가 위 고정 피해 + 비율 피해로 체감되는지
3. Crit Cast가 근접 치명타/강공격과 활·석궁 일반 적중에서 발동하고, 주문의 부가 수치를 과대 피해로 사용하지 않는지
4. 완성 룬워드 재련 후 룬워드 효과, Grief 진화 XP, Infinity 모드가 유지되고 재련 오브가 정확히 1개만 소모되는지
5. 전투 중 저장/불러오기와 함정 설치·지역 이동 후 오래된 피해나 사라진 함정 같은 상태 이상이 없는지
6. Prisma 패널의 재련 안내와 호환성 경고가 실제 동작과 일치하는지

정적·빌드·패키징 검증은 완료했지만 Skyrim 인게임 확인은 아직 완료하지 않았습니다. 문제가 발생하면 `Documents/My Games/Skyrim Special Edition/SKSE/CalamityAffixes.log`와 크래시 로그를 함께 첨부해 주세요.
