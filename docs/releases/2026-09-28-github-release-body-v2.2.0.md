# Calamity - Reactive Loot & Affixes v2.2.0

v2.2.0은 **선택 재련에 장비당 6회 제한**을 두고, 정제 오브를 그 리셋 수단으로 만든 제작 균형 업데이트입니다. 2.1.4-rc1에서 공개 테스트한 한국어 표기 "칼라미티"도 포함합니다. ESP와 게임 데이터는 2.1.3과 같고, 코세이브에 레코드 하나가 추가됩니다.

## 왜 바꿨나요

2.0부터 선택 재련은 나머지 어픽스를 지킨 채 하나만 다시 굴리고, 횟수 제한이 없었습니다. 그러다 보니 좋은 옵션까지 날리는 정제보다 언제나 유리해서, 더 희귀한 정제 오브가 쓸 곳이 없었습니다(제작 방식을 제안해 주신 분의 지적입니다).

재료 흐름을 모의실험해 보니 드랍률을 뒤집어 재련 오브를 희귀하게 만들어도 정제는 거의 쓰이지 않고 제작만 두 배 느려졌습니다. 어픽스가 3칸뿐이라 하나씩 고치는 쪽이 항상 이기기 때문입니다. 정제에 역할을 주는 방법은 제안자의 원래 설계, 즉 **재련 횟수 제한과 정제 리셋**이었습니다. 횟수는 스카이림의 처치 속도에 맞춰 6회로 정했습니다.

## 바뀐 점

- **선택 재련: 장비마다 6회.** 다 쓰면 재련 버튼이 꺼지고, 정제 오브로 어픽스를 전부 다시 굴리면 6회를 되돌려 받습니다. 어픽스가 없는 장비를 확인 스크롤로 감정해도 새로 시작합니다. 슬롯 확장은 횟수에 들어가지 않습니다.
- **정제 오브 기본 드랍률 2% → 4%.** 리셋에 꼭 필요한 재화가 되어 조금 흔하게 했습니다. MCM 슬라이더를 바꾸지 않았다면 새 기본값이 적용되고, 직접 바꾼 값은 그대로 유지됩니다.
- **확인 스크롤 교환: 정제 오브 15:1 → 10:1.** 재련 오브는 3:1 그대로입니다.
- **패널:** 비용 줄에 이 장비에 남은 재련 횟수(예: `4/6`)가 나오고, 다 쓴 장비는 정제를 안내합니다. 정제 버튼 설명에도 재련 횟수가 돌아온다고 적었습니다.
- **한국어 표기:** 게임 안 문구의 "칼래미티"를 "칼라미티"로 바꿨습니다(MCM 단축키 이름 "칼라미티 패널 토글", 패널 제목 등 12곳).

모의실험(원하는 접두 15%, 접미 20% 가정)에서 좋은 장비 하나를 완성하는 데 드는 처치 수 중앙값은 약 11% 늘고, 정제 오브는 장비당 약 6회 쓰이는 핵심 재화가 됩니다.

## 호환성

- 장비별 재련 횟수를 새 코세이브 레코드(`IRFC`)에 저장합니다. 기존 세이브를 그대로 쓸 수 있고, 기존 장비는 0회부터 시작합니다.
- 이전 DLL은 이 레코드를 건너뛰므로 예전 버전으로 되돌려도 세이브는 열립니다. 그 경우 재련 횟수만 사라집니다.
- 장비를 팔거나 옮기거나 정리할 때 재련 횟수도 함께 따라가거나 지워집니다.

## 확인한 범위

- 2026-09-28 사용자가 테스트 빌드로 인게임에서 확인했습니다: 재련할 때마다 남은 횟수가 줄고, 0이 되면 재련이 막히며, 정제하면 6/6으로 돌아오고, 저장 후 불러와도 횟수가 유지되며, 장비마다 따로 셉니다.
- 저장 형식 골든 테스트를 레코드 9개로 늘렸고(잘린 데이터 처리 포함), 제한 정책 정적 검사와 패널 테스트를 추가했습니다. Python·생성기·SKSE 검사와 배포 패키지 검증을 통과했습니다.
