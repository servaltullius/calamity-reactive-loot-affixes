# Calamity - Reactive Loot & Affixes v2.0.0

v2.0.0은 어픽스 제작을 **확인 → 선택 재련 → 정제**의 세 단계로 나눈 정식 릴리스입니다. 디아블로 2식 미확인 장비 감정과 PoE식 크래프팅을 합친 흐름으로, 원하는 효과를 하나씩 맞춰 가거나 희귀 재화로 전부를 새로 굴리는 선택지를 줍니다. 기존 세이브와 호환됩니다.

## 새 제작 흐름

| 작업 | 결과 | 비용 |
| --- | --- | ---: |
| 확인 | 일반 어픽스가 없는 장비에 1~3개 부여(60%/30%/10%) | 확인 스크롤 1개 |
| 선택 재련 | 고른 일반 어픽스 하나만 같은 종류(접두/접미)로 교체 | 재련 오브 2개 |
| 슬롯 확장 1 → 2 / 2 → 3 | 기존 어픽스를 유지하고 접미 추가 | 재련 오브 2개 / 4개 |
| 정제 | 슬롯 수를 유지한 채 일반 어픽스 전부를 한 번에 다시 굴림 | 정제 오브 1개 |

- 첫 어픽스는 이제 **재련 오브가 아니라 확인 스크롤**로 부여합니다. 보유한 재련 오브는 선택 재련과 슬롯 확장에 그대로 씁니다.
- 선택 재련은 횟수 제한이 없고, 바꾸지 않은 어픽스의 성장 상태와 룬워드를 그대로 둡니다.
- 정제는 6초 안에 한 번 더 눌러 확정합니다. 기존 일반 어픽스와 그 성장 상태는 사라지고 같은 슬롯 수로 새 어픽스가 붙습니다. 결과가 이전과 완전히 같으면 오브를 쓰지 않습니다. 구버전 세이브의 비정상 어픽스 구성도 정제로 정상 구성이 됩니다.
- 모든 작업은 완성된 룬워드와 그 성장 상태를 보존합니다.

## 새 재화 획득

- 플레이어나 플레이어 소환수가 처치한 적격 적대 대상의 시체에서 **확인 스크롤 20%**, **정제 오브 2%**로 각각 독립 판정합니다. 기존 룬 조각·재련 오브 보상은 그대로이며, 같은 시체에서 다시 판정하지 않습니다.
- 두 확률은 MCM의 새 슬라이더로 조정하고 `user_settings.json`에 저장됩니다. 새 재화에는 보스 확정 보상이나 피티가 없습니다.

## 패널과 MCM

- "제작 재료" 대시보드에서 재련 오브·확인 스크롤·정제 오브 보유량을 한 번에 봅니다. 제작 버튼은 확인 → 선택 재련 → 슬롯 확장 → 정제 순서이고, 교체할 어픽스 목록은 기본으로 펼쳐집니다.
- 넓은 패널 레이아웃(기본 1320×860 포함)에서 룬워드 탭의 레시피 목록이 약 30px로 눌려 거의 보이지 않던 문제를 고쳤습니다. 룬 그리드 칸이 잘리던 문제와, 작은 패널에서 베이스 목록이 아래로 넘쳐 고를 수 없던 문제도 고쳤습니다.
- 무료 전체 초기화는 디버그 모드 전용이 되었고, 일반 플레이에서는 해당 섹션이 보이지 않습니다. 일반 어픽스를 새로 굴리려면 정제 오브를 사용하세요.

## 확인한 범위

- 2026-09-26 사용자가 새 재화 드랍, 확인·선택 재련·정제, 새 패널 배치와 MCM 슬라이더를 인게임에서 확인했습니다.
- DLL 빌드, Python 188개·생성기 170개 테스트, SKSE/호스트 검사, Papyrus 재컴파일과 배포 패키지 검증을 통과했습니다. ESP는 기존 레코드 783개의 FormID·종류·EditorID가 1.7.5와 동일하고 새 재화 2개(`0xB0F`, `0xB10`)만 끝에 추가됐습니다.
- 패널은 Chromium으로 6가지 패널 크기 × 3개 언어 × 접힘 상태 × 3개 탭(108개 조합)과 1280×720 화면에서 잘림·스크롤을 측정해 문제가 없음을 확인했습니다.
- 모든 장비 종류·모드 조합과 저장/로드 시점을 각각 인게임 검증했다는 뜻은 아닙니다.

## 설치와 업데이트

1. 게임을 종료하고 세이브를 보관합니다.
2. **`CalamityAffixes_MO2_v2.0.0_2026-09-26.zip`** 전체를 설치합니다. 새 재화가 ESP에 추가됐으므로 DLL만 교체하면 동작하지 않습니다.
   - 이전 Calamity 모드가 있으면 MO2에서 **Replace**로 덮어쓰거나, 새 모드로 설치했다면 **이전 버전 모드를 비활성화**해 두 버전이 동시에 켜지지 않게 합니다. 이전 모드의 `CalamityAffixes_DISTR.ini`가 남아 우선 적용되면 구버전 통화 분배가 되살아날 수 있습니다.
3. SKSE로 실행합니다. 새 게임은 필요하지 않으며 기존 장비의 어픽스·슬롯·룬워드와 보유 재화는 그대로입니다.

**1.2.x(넥서스 구버전)에서 바로 올라오는 경우**

- 통화는 이제 적격 적대 시체에서만 나오며 상자·월드·SPID 분배는 없습니다. SPID는 더 이상 필요하지 않습니다.
- 소환수 보호(1.7.5)는 새로 소환한 개체부터 적용됩니다. 이미 소환된 개체는 사라진 뒤 다시 소환하세요.
- 판매·보관으로 다른 장비에 예전 어픽스가 옮겨 보이는 구버전 상태는 자동 복구하지 않습니다. MCM에서 디버그 알림을 켜고 고급 탭의 **상태 초기화**로 정리하세요.
- 1.3~1.7.5의 전체 변경 내역은 [CHANGELOG](https://github.com/servaltullius/calamity-reactive-loot-affixes/blob/main/CHANGELOG.md)에 있습니다.

Prisma UI는 이 ZIP에 포함되지 않습니다. 공개 자산은 **MO2 ZIP, ZIP SHA256, DLL, ESP** 네 개이며 일반 설치에는 전체 ZIP을 사용하세요. 일치하는 PDB는 GitHub Actions의 별도 심볼 산출물로 보존합니다.
