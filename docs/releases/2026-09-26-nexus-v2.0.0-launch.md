# v2.0.0 넥서스 새 페이지 배포 키트

2.0.0은 기존 페이지(https://www.nexusmods.com/skyrimspecialedition/mods/172116, 넥서스 버전 1.2.21·추천 33)를 업데이트하지 않고 **새 페이지**로 올린다. 이유는 신규 노출이다. 넥서스 규정상 금지는 아니지만 사실상 같은 모드 페이지를 둘 다 살려 두면 통합 요청을 받을 수 있으므로, **옛 페이지는 반드시 은퇴 처리**한다.

## 1. 새 페이지

**제목(택 1)**
- `Calamity 2 - Reactive Loot and Affixes (Diablo2 PoE)` — 옛 제목의 검색어를 유지하면서 구분된다(권장)
- `Calamity - Reactive Loot and Affixes 2 (Diablo2 PoE)`

**버전:** `2.0.0`
**필수 요구:** SKSE64, Address Library for SKSE Plugins, Prisma UI
**권장:** SkyUI, MCM Helper, KID / 선택: I4
**본문:** `docs/NEXUS_DESCRIPTION.md` 전체를 붙여 넣는다. 맨 위에 아래 한 줄을 추가한다.

> 이 페이지는 Calamity의 2.0 이후 버전입니다. 1.x(구 페이지)에서 세이브를 그대로 이어서 쓸 수 있습니다. / This is Calamity 2.0 and later. Saves from 1.x (the old page) carry over.

**짧은 소개(Brief overview)**

- 한국어: 디아블로 2·PoE식 어픽스와 룬워드 94종을 스카이림 장비에 부여하는 SKSE 모드. 확인 스크롤로 감정하고, 재련 오브로 원하는 효과 하나를 다듬고, 정제 오브로 전부를 다시 굴립니다. 재료는 처치한 적의 시체에서만 나옵니다.
- English: Diablo 2 / PoE-style affixes and 94 runewords for your own Skyrim gear, via SKSE. Identify with a scroll, refine one chosen affix with Reforge Orbs, or reroll them all with a rare Scouring Orb. Materials drop only from enemies you kill.

**메인 파일**
- 파일: GitHub 릴리스의 `CalamityAffixes_MO2_v2.0.0_2026-09-26.zip`(SHA256은 같은 릴리스의 `.sha256`)
- 이름: `Calamity 2.0.0 (MO2 / Vortex)`
- 설명: `전체 설치 파일. DLL만 교체하지 마세요. 1.x에서 올라오면 이전 Calamity 모드를 비활성화하세요. / Full install. Do not swap only the DLL. Disable any older Calamity mod when upgrading from 1.x.`

**넥서스 변경 이력(2.0.0)**
- 제작을 확인 스크롤(1~3개 부여) · 선택 재련(어픽스 하나 교체) · 정제 오브(전체 리롤)로 개편
- 새 재화 2종을 적 시체에서 획득(20% / 2%, MCM 조정 가능)
- 제작 재료 대시보드와 정리된 제작 버튼, 넓은·작은 패널의 표시 잘림 수정
- 1.2.21 이후의 전체 변경: 시체 전용 통화 드랍, 슬롯 확장, 함정 표시, 소환수 아군 피해 보호, 전투 프리징 수정 등(GitHub CHANGELOG)

## 2. 옛 페이지 은퇴

새 페이지가 공개된 뒤에 한다.

1. 옛 페이지의 파일을 **Archived**로 옮긴다. 페이지와 댓글은 지우지 않는다(기존 사용자가 찾아올 수 있게).
2. 설명 맨 위에 아래 공지를 넣고, 같은 내용을 **고정 댓글(sticky)**로 올린다.
3. 옛 페이지 제목 끝에 `[moved to Calamity 2]`를 붙이는 것도 고려한다.

**공지문**

> **개발은 새 페이지에서 계속됩니다 → Calamity 2** (새 페이지 링크)
> 2.0부터 제작 방식이 확인 스크롤·재련 오브·정제 오브로 바뀌었고, 1.2.21 이후 반년 치 개선이 들어 있습니다. 세이브는 그대로 이어서 쓸 수 있습니다. 새 버전을 설치할 때는 이 페이지의 모드를 **비활성화하거나 제거**해 두 버전이 동시에 켜지지 않게 해 주세요.
>
> **Development continues on the new page → Calamity 2** (new page link)
> 2.0 reworks crafting around Identify Scrolls, Reforge Orbs, and Scouring Orbs, and includes six months of improvements since 1.2.21. Your saves carry over. When installing the new version, **disable or remove** the mod from this page so both versions are never active together.
