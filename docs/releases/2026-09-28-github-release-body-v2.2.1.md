# Calamity - Reactive Loot & Affixes v2.2.1

v2.2.1은 **영어 UI에서도 룬워드 레시피 이름이 한국어로 나오던 문제**를 고친 릴리스입니다. 게임 동작, ESP, 코세이브, 게임 데이터는 2.2.0과 같습니다.

## 고친 점

- **패널의 룬워드 이름이 UI 언어를 따릅니다.** DLL이 레시피 이름을 한국어 하나만 보내고 있어서, 영어로 플레이해도 레시피 목록·선택한 레시피·"Recipe:" 상태 줄에 "스피릿", "집착" 같은 이름이 나왔습니다. 이제 영어·한국어 이름을 함께 보내고 패널이 언어 설정에 맞춰 고릅니다.

  | UI 언어 | 표시 |
  | --- | --- |
  | 영어 | `Spirit [Tal-Thul-Ort-Amn]` |
  | 한국어 | `스피릿 [Tal-Thul-Ort-Amn]` |
  | 이중 언어 | `Spirit / 스피릿 [Tal-Thul-Ort-Amn]` |

- **레시피 검색은 두 이름 모두로 찾습니다.** 영어 모드에서 "스피릿"을, 한국어 모드에서 "spirit"을 검색해도 나옵니다.
- **HUD 알림은 영어 이름을 씁니다.** "Runeword Recipe:", "Runeword Complete:" 알림과 패널의 변환 완료 메시지는 영어 문장입니다. 그래서 이름도 영어로 맞췄습니다. 영어판 스카이림의 HUD 글꼴에는 한글이 없어 이름이 보이지 않을 수 있었습니다.

툴팁의 룬워드 어픽스 이름("Runeword Spirit" / "룬워드 스피릿")은 원래 언어 설정을 따르고 있었으므로 바뀌지 않습니다.

## 호환성

- 기존 세이브를 그대로 쓸 수 있습니다. 코세이브 형식은 2.2.0과 같습니다.
- 새 패널은 이전 DLL과 함께 쓰면 예전처럼 한국어 이름을 보여 줍니다. DLL과 패널은 같은 ZIP으로 함께 설치하세요.

## 확인한 범위

- 실제 패널을 헤드리스 브라우저로 띄워 영어·한국어·이중 언어 모드에서 목록·선택 레시피·상태 줄 이름과 두 언어 검색을 확인했습니다. 영어 모드 목록에는 한글이 없습니다.
- 패널 동작 테스트(언어별 이름, 이전 DLL 대비, 검색)와 SKSE 정책 검사를 추가했습니다. 정책 검사는 수정을 빼면 실패하는 것을 확인했습니다. Python·생성기·SKSE 검사와 배포 패키지 검증을 통과했습니다.

## 설치와 업데이트

1. **`CalamityAffixes_MO2_v2.2.1_2026-09-28.zip`** 전체를 설치합니다. DLL과 패널이 함께 바뀌었으므로 MO2에서 기존 Calamity 모드를 **Replace**하세요.
2. 새 게임은 필요하지 않습니다.

Prisma UI는 이 ZIP에 포함되지 않습니다. 공개 자산은 **MO2 ZIP, ZIP SHA256, DLL, ESP** 네 개입니다.
