# Calamity - Reactive Loot & Affixes v1.7.5-rc6

rc6는 전투 중 프리징을 일으키는 이벤트 락 교착 경로를 수정하고, 일반 공격 발동·중복 옵션 강화·시전자와 비적대 대상 보호를 보강한 공개 테스트 빌드입니다. rc5의 어픽스 슬롯 확장과 드래곤 확정 보상도 포함합니다.

## 전투 프리징 수정

- 간파베기 중 반복된 프리징의 두 덤프에서 Calamity 상태 락과 Skyrim 마법효과 이벤트 락이 서로를 기다리는 같은 경로를 확인했습니다.
- 이벤트가 상태 락을 즉시 얻지 못하면 입력을 보관하고 순서대로 처리하도록 8개 이벤트 진입점을 수정했습니다. 무경합 시 기존 즉시 처리를 유지합니다.
- 피격 데이터·원래 proc 재진입 문맥·객체 수명을 보존하고, 로드/Revert 이후 이전 이벤트가 실행되지 않도록 세대를 검증합니다. 발동 확률과 ICD의 공유 상태 보호도 유지합니다.
- 테스트 패키지 사용 후 2026-09-05 사용자가 “해결된것같아”라고 보고했습니다. 반복 횟수나 모든 전투 상황의 결과가 제공된 것은 아니며, SkyrimHunter 모션이나 FSMP/overlay 자체를 원인으로 확정한 것은 아닙니다.

## 일반 공격 발동과 중복 옵션 강화

- 곰 덫은 일반 무기 적중에서 기본 40%, 파이어볼트·아이스 스파이크·라이트닝 볼트는 일반 근접 적중에서 45%, 썬더볼트·아이스 스피어·체인 라이트닝·아이스 스톰은 35%로 발동합니다. 장착 구성·페널티·ICD에 따라 실제 빈도는 달라집니다.
- 치명타·강공격은 기존 판정을 사용하며 평타 확률을 추가로 이중 판정하지 않습니다. 활·석궁 치명 시전의 기존 정상 무기 적중 경로도 유지합니다.
- 다른 장비에 중복 장착한 동일 표준 발동 어픽스는 강한 사본부터 최대 3개까지 확률을 점감 합성합니다. 효과·발동 예산·ICD는 한 번만 소비합니다.
- 단계형 접미는 장착 티어를 합산해 `T1+T1→T2`, `T1+T2→T3`으로 강화되며 T3에서 제한됩니다.
- 근접 치명타·강공격은 서로 다른 치명 시전 주문을 최대 2개까지 발동합니다. 일반 근접 공격과 활·석궁은 최대 1개, 전역 ICD는 발동 묶음당 0.15초를 유지합니다.

## 시전자·아군·중립 보호

- Calamity의 공격 주문·피해 전환·함정·시체 폭발은 적대 대상에게만 적용하도록 보강했습니다. 광역 효과에도 적대 및 팀메이트 제외 조건을 적용합니다.
- 폭발 패밀리어 등은 Calamity가 실제 소환한 개체와 해당 개체가 유발한 폭발을 추적해 비적대 대상 체력 피해를 억제합니다.
- 일반 플레이어 공격과 수동 주문의 바닐라 아군 피해 규칙은 유지합니다. 소환 폭발의 체력 피해 보호에는 Calamity 체력 피해 훅이 정상 설치되어 있어야 합니다.

## 검증과 설치

- Python 테스트 184개, Generator 테스트 166개, SKSE/host CTest 및 새 동시성 검사 13개를 통과했습니다. 동시성 검사는 100회 반복, ASan/UBSan 및 교착을 다시 넣으면 실패하는 변이 검사도 통과했습니다. TSAN은 WSL 실행 환경 문제로 검증하지 못했습니다.
- 이번 프리릴리스는 위 사용자 개선 보고와 자동 검증을 근거로 게시합니다. 모든 효과·모드 조합에 대한 인게임 확인을 의미하지 않습니다.
- 기존 코세이브 형식과 기존 레코드 FormID를 유지하고, 비적대 보호용 주문 레코드를 추가했습니다. 기존 세이브를 이어 사용할 수 있도록 설계했으며 새 게임을 요구하지 않습니다.
- 게임을 완전히 종료한 뒤 MO2에서 이전 모드를 **Replace**로 교체하세요. 업데이트 전 사용자 설정과 세이브를 보관하세요.
- 권장 설치 파일은 `CalamityAffixes_MO2_v1.7.5-rc6_2026-09-05.zip`입니다. 공개 자산은 MO2 ZIP·ZIP SHA256·DLL·ESP 네 개이며, 일치 PDB는 별도 GitHub Actions 심볼 산출물로 보존합니다.

문제가 다시 발생하면 실제 설치 DLL의 해시, 해당 버전의 `CalamityAffixes.log`, 가능하면 새 hang dump를 함께 제공해 주세요.
